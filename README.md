## About

I'm **Raja** — Co-Founder & CTO at **[Apyrn Labs](https://apyrn.com)**, based in India 🇮🇳.

I design and build **enterprise integration platforms, canonical data models, and AI agent infrastructure** for organizations that need their systems to talk to each other reliably. My work sits where enterprise architecture meets applied AI: turning fragmented business APIs into coherent, governed, AI-ready platforms.
